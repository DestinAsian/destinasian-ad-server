📝 Integration Guide

Step 1: Load Ad Script

<script src="http://localhost:5001/ads.js"> </script>

Step 2: Add Ad Container

<div id="ad-container"> <img src="banner.jpg" /> </div>

Step 3: Track Events

fetch('/api/tracking/ {adCode}/impression', {method: 'POST'})
Setup: Backend runs on http://localhost:5001
Dashboard: Access analytics at http://localhost:3000

🔌 API Reference

Record Impression

POST /api/tracking/{adCode}/ impression

Record Click

POST /api/tracking/{adCode}/ click

Get Campaign Stats

GET /api/campaigns/{id}/ stats
All endpoints return JSON responses. CORS enabled for cross-origin requests.

🧪 Testing

cURL - Record Impression

curl -X POST \ http://localhost:5001/\ api/tracking/\ {adCode}/impression

cURL - Record Click

curl -X POST \ http://localhost:5001/\ api/tracking/\ {adCode}/click
Tip: Use the buttons above to test impression and click tracking in real-time.

✨ Best Practices

✓ Do:
  • Record impressions when ad becomes visible
  • Record clicks when user clicks the ad
  • Use unique ad codes for tracking
  • Implement ad lazy loading
  • Cache ad responses
✗ Don't:
  • Record duplicate impressions
  • Click track without impression
  • Block tracking endpoints
  • Share ad codes between ads
  • Expose API credentials
