How to Integrate

Simply add the ad server script to your page:

<script src="http://localhost:5001/ad-client.js"></script>

<!-- Add ad containers with data-ad-code attribute -->
<div id="my-ad" data-ad-code="ad-unit-1" data-width="100%"></div>

<script>
  // Manually load specific ad
  AdServer.loadAd('my-ad');
  
  // Or use auto-load for all ads with data-ad-code
  // (automatically runs on page load)
</script>

API Reference

  • AdServer.loadAd(containerId) - Load ad in specific container
  • AdServer.recordImpression(adCode) - Manually record impression
  • AdServer.recordClick(adCode) - Manually record click
  • AdServer.getAdStats(adCode) - Get ad statistics
  • AdServer.autoLoad() - Load all ads with data-ad-code

Configuration

Update the API_BASE URL in ad-client.js to match your ad server:

const API_BASE = 'http://your-ad-server.com/api';
